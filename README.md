The API lives in `backend/` and runs on **https://api.donish.live** (Node + PM2 + nginx + PostgreSQL on VPS).

See **[backend/DEPLOY.md](backend/DEPLOY.md)** for environment variables, deploy steps, and DNS/TLS setup.
